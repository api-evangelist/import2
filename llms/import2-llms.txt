# Import2

> Import2 is a fully automated data-migration platform that moves customer data between SaaS applications (CRM, helpdesk, and project-management tools) without CSVs or custom development. The Import2 API v2.1 lets partners and vendors programmatically create and track migration jobs.

## APIs

- [Import2 API v2.1 Reference](https://import2.github.io/): HTTP Basic auth; base URL https://www.import2.com/api/v2.1 (sandbox https://www.import2.com/api/sandbox). Endpoints for supported tools and import lifecycle.

- [OpenAPI (API Evangelist)](openapi/import2-openapi.yml): Import2 API v2.1 authored from the published reference.
